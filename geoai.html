How to learn from this

Every lesson starts with a map or a picture, then a hand-worked example on a tiny raster, table or catalogue, then the formal definition, an animated lab you can edit, traps, real datasets and self-check questions. STAC lessons show real JSON you can read; STAC MLM lessons show how a model describes itself.

The maths and ML are linked, not repeated: when a lesson needs a metric, a loss or a backbone, it points to the matching Machine Learning or Computer Vision lesson.

The GeoAI pipeline

Every GeoAI product follows these six stages, from a catalogue search to a published map. Click a stage for what it does, what it needs and where its data is stored.

The map

Modules 0–1 set up the geography and the file formats. Module 2 is STAC: how data is found. Module 3 prepares it for learning, and Module 4 starts with classical methods. Module 5 is deep learning on imagery. Module 6 is STAC MLM: how models are described and run. Module 7 covers foundation models and embeddings. Module 8 measures whether a map is right, and Module 9 deploys it responsibly.
