How to learn from this

Go in order the first time: each lesson only uses ideas from the ones before it. Inside a lesson the rhythm is always the same:

  1. The question — a real problem that makes the idea necessary.
  2. Intuition — the idea in plain words and pictures, before any symbols.
  3. Build it up — a worked example with real numbers, then the formal definition with every symbol explained.
  4. Lab — change numbers or equations and watch the result move. Following the "try this" steps is the fastest way to understand.
  5. Where it shows up in AI, common traps and check yourself questions.
Already know some of it?Skim the "Check yourself" questions of a lesson first. If you can answer all three, mark it complete and move on.

The map

Training a model is a loop of four moves, each from a different branch of mathematics. Foundations (module 0) is the shared language; modules 1–5 supply the four branches; module 6 puts them together into optimisation; modules 7–8 apply everything to modern networks and generative models.
