How to learn from this

Every lesson starts with a decision problem, a bandit, a gridworld or a game. Then comes a hand-worked example on a 2–4 state chain or a 3×3 grid, the formal definition, an animated lab you can edit, traps, real uses and self-check questions. Values are shown moving backwards through time, so you can see credit being assigned.

The maths and ML are linked, not repeated: expectations and gradients point to Mathematics, value and policy networks to Machine Learning, and robot policies to Robotics.

The learning loop

Every reinforcement learning system runs these six stages, over and over. Click a stage for what it does, what it needs and where its data is stored.

The map

Module 0 defines the problem: the agent, the environment, the return and the Markov decision process. Module 1 covers bandits and exploration, and Module 2 dynamic programming with a known model. Module 3 learns from complete episodes with Monte Carlo methods, and Module 4 learns from every step with temporal-difference methods. Module 5 scales these ideas with function approximation and deep Q-learning, and Module 6 learns policies directly with actor–critic methods and PPO. Module 7 uses learned models, Module 8 covers advanced topics such as offline and multi-agent RL, and Module 9 applies RL to alignment, games and real systems.
