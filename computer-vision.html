How machines see: from a single pixel to the architectures behind modern vision systems. How to learn from this

Each lesson follows one rhythm: a visual question, intuition in plain words, a worked example with real numbers, the formal definition, an animated lab you can edit, then traps, real-world uses and self-check questions. Architecture lessons end with a "draw it yourself" blueprint: block diagram, tensor shape at each stage, parameter count.

Maths prerequisites are light — if sums, vectors, matrices and derivatives feel new, keep the Mathematics for AI course open beside this one.

The vision pipeline

Every vision system, from a phone camera filter to a self-driving stack, is this same flow. Click a stage to see what runs there, on which hardware, and what is stored.

Preview: an architecture, animated

Boxes are tensors: height ∝ image size, thickness ∝ channels. Watch the white pulse enter a network, see the image shrink while the channels grow, and see skip connections carry information around blocks. Choose another model, change the input resolution, or edit the architecture text and the shapes, parameters and compute update instantly. All numbers match the published models.

The map

Modules 0–2 are the classical foundations (pixels, filters, geometry). Module 3 builds the convolutional network from first principles; modules 4–5 are the architecture gallery (CNN blueprints, then transformers); 6–8 apply backbones to detection, segmentation and generation; module 9 turns models into real systems.
